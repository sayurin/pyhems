# 0008. 範囲が未設定の計測値リストを、1 回だけ SetC で初期化する

- ステータス：承認
- 日付：2026-10-31

## コンテキスト

分電盤メータリング（`0x0287`）の計測値リストは、取得するチャンネルの範囲を別の EPC で指定する。

| 計測値リスト | 範囲指定 | チャンネル数 |
|---|---|---|
| `0xB3` 積算電力量計測値リスト（片方向） | `0xB2` | `0xB1` |
| `0xB5` 瞬時電流計測値リスト（片方向） | `0xB4` | `0xB1` |
| `0xB7` 瞬時電力計測値リスト（片方向） | `0xB6` | `0xB1` |
| `0xBA` 積算電力量計測値リスト（双方向） | `0xB9` | `0xB8` |
| `0xBC` 瞬時電流計測値リスト（双方向） | `0xBB` | `0xB8` |
| `0xBE` 瞬時電力計測値リスト（双方向） | `0xBD` | `0xB8` |

[issue #98](https://github.com/sayurin/hems_echonet_lite/issues/98) で報告された分電盤は、一度も設定されていない初期状態だった。範囲指定が未設定のままなので、計測値リストの開始チャンネルや範囲として `0xFD` を返し、チャンネルごとの値を読み出せなかった。

同じ分電盤に接続された別のコントローラ（例えばメーカー純正の HEMS コントローラ）があれば、そのコントローラが範囲を設定する。そのため、多くの環境では問題にならない。一方、ECHONET Lite の仕様には、誰がいつ範囲を初期化すべきかが明確に書かれていない。

## 決定

- 計測値リストの値を受け取り、その開始チャンネルまたは範囲が `0xFD`（未設定）の場合、対応する範囲指定 EPC に SetC を 1 回だけ送る。
  - 設定する値は、開始チャンネルを 1、範囲を「チャンネル数」と「1 回に指定できる上限」の小さいほうとする。上限は `0xB3`・`0xB5`・`0xB7`・`0xBC`・`0xBE` で 60、`0xBA` で 30 とする。
  - チャンネル数が取得できていない場合や、1〜252 の範囲外の場合は送らない。
- 送るのは、範囲指定 EPC ごとにランタイムあたり 1 回だけとする。送信に失敗しても、拒否されても、応答がなくても再試行しない。結果はログに記録する。
- すでに範囲が設定されている計測値リストには何もしない。
- 計測値リスト・チャンネル数・範囲指定の対応と上限は、`scripts/custom_definitions.yaml` の `collection_bindings` で定義する。MRA にはこの対応が書かれていないためである。

## 結果

- 初期状態の分電盤でも、チャンネルごとの値を読み出せる。
- 利用者の操作なしに、機器の設定を書き換える。
- 別のコントローラがすでに範囲を設定していれば何もしないので、そのコントローラの設定と競合しない。
- 初期化に失敗した場合は、次にランタイムを起動するまで再試行しない。
